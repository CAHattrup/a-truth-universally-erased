# A Truth Universally Erased

*Create your own poem using Jane Austen's words.*

**[Try it now →](https://cahattrup.github.io/a-truth-universally-erased/)**

It is a truth universally acknowledged that a poet in possession of a good novel must be in want of a black marker.

## What is erasure poetry?

Erasure poetry is a way of writing a new poem from existing text. You start with a page someone else wrote and remove words until only your poem remains.

## How to use this tool

1. Choose a novel and a page.
2. Choose words. Select the words and punctuation marks you want to keep. Select again to let them go.
3. View the inked page. Choose a style:
   - **Blackout:** Black bars over everything you didn't keep
   - **White-out:** The unchosen words disappear
   - **Highlighter:** Your chosen words marked in yellow, pink, green, or blue
4. Or, choose **Poem only**, which shows just your words, with each run of neighboring words on its own line.
5. **Save as image** to keep or share your poem. The image includes a credit line naming the novel and chapter.

No account or installation required. It works in any modern web browser, on computers, tablets, and phones.

## Running it on your own computer

You don't need to. The tool runs on the web at the link above. But if you'd like a copy (for a classroom without reliable internet, for example):

1. Click the green **Code** button on this page, then **Download ZIP**.
2. Extract (unzip) the folder.
3. Open the extracted folder and double-click `index.html`. The tool opens in your web browser.

Keep all the files together in that folder.

## Suggest a favorite page

Have a page you love? Open an [issue](../../issues) with:

- The novel
- The first several words where the page should start (or a line the page should include)
- A short name for the page, written as an action, such as *Mr. Collins proposes*

Favorite pages live in [`pages.js`](pages.js). Instructions at the top of that file explain how to add one.
